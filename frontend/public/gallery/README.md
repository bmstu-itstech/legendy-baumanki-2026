# Фотографии для блока «Как это было в прошлом году»

Просто кладите картинки в эту папку — код ничего знать о них не должен.

Правила:

- Имена любые; порядок на сайте — по алфавиту с «естественной» сортировкой
  чисел (`2.jpg` идёт раньше `10.jpg`). Если порядок важен — называйте
  файлы с номерами: `1-сцена.jpg`, `2-награждение.jpg` и т.д.
- Форматы: jpg, png, webp, avif, gif, svg.
- Берутся первые 5 файлов, остальные игнорируются (шестое окно —
  карточка-ссылка на фотоальбом).
- Пропорция кадра 370×252 (или кратная); для ретины — 740×505 и больше.
- Мест больше, чем фото? Пустые слоты останутся заглушками цвета макета.
- Файлы подхватываются автоматически: в dev-сервере — сразу, в собранной
  версии — после пересборки (`npm run build`).
