# Фотографии для блока «Как это было в прошлом году»

Список файлов захардкожен в `components/home/gallery.tsx` (константа
`GALLERY_PHOTOS`), а не читается автоматически из этой папки — так
не зависит от того, что реально закоммичено и доехало до сборки/докера.

Чтобы добавить или заменить фото:

1. Положите картинку сюда, в `public/gallery/`, и закоммитьте файл.
2. Добавьте (или замените) её путь в `GALLERY_PHOTOS` в
   `components/home/gallery.tsx`.

Правила:

- Берутся первые 5 путей из `GALLERY_PHOTOS`, остальные игнорируются
  (шестое окно — карточка-ссылка на фотоальбом).
- Пропорция кадра 370×252 (или кратная); для ретины — 740×505 и больше.
- Форматы: jpg, png, webp, avif, gif, svg.
